# Нотный блокнот 𝄞

Приложение для планшета, чтобы хранить ноты и делать в них пометки стилусом
(Apple Pencil, S Pen и любой другой стилус). Работает без интернета, все данные
хранятся на самом устройстве.

## Возможности

**Библиотека**
- Импорт нот из **PDF** и **фотографий/сканов** (несколько фото сразу → одна партитура).
- **Нотные тетради**: чистая нотная бумага (8–14 станов, фортепианные системы или чистый лист).
- Поиск по названию и автору, сортировка, избранное, копирование, удаление.
- **Резервная копия** всей библиотеки в один файл и восстановление из него
  (для переноса на другое устройство).
- **Печать / сохранение в PDF** вместе со всеми пометками.

**Редактор**
- **Ручка** с учётом силы нажатия, **маркер** (полупрозрачный), **ластик** (стирает штрих целиком).
- **Текст** — пометки курсивом, как в нотах; тап по пометке — изменить, перетаскивание — сдвинуть.
- **Обозначения** одним касанием: динамика (*pp, mf, ff, sfz…*), темп (*cresc., rit., a tempo…*),
  знаки (♯ ♭ ♮, акцент, дыхание, Ped., 8va…), аппликатура 1–5.
- Цвета и толщина — повторное нажатие на выбранный инструмент.
- **Отмена/повтор** (в т.ч. Ctrl+Z / Ctrl+Y).
- **Режим стилуса** (включается сам, когда планшет «видит» стилус): рисует только стилус,
  а пальцем можно листать, двигать и масштабировать — ладонь не оставляет следов.
- Масштаб щипком двумя пальцами, двойной тап — вернуть масштаб.
- Листание: свайп, касание у края страницы, кнопки, клавиши ←/→, PageUp/PageDown —
  то есть работают и **Bluetooth-педали для перелистывания нот**.
- **Режим выступления** ▶: полный экран, без панелей, экран не гаснет.
- Панель страниц: миниатюры, добавление (нотный стан, чистый лист, PDF/фото), перестановка и удаление страниц.

## Как запустить на планшете

Это веб-приложение (PWA) — его не нужно публиковать в App Store / Google Play.
Достаточно один раз открыть его по адресу `https://…` и добавить на главный экран.

### 1. Опубликовать (бесплатно, через GitHub Pages)
1. На GitHub откройте репозиторий → **Settings → Pages**.
2. В **Source** выберите *Deploy from a branch*, ветку `main` (или нужную) и папку `/ (root)`, нажмите **Save**.
3. Через минуту приложение будет доступно по адресу вида
   `https://<ваш-логин>.github.io/Blocknot_dlya_not/`.

### 2. Установить на планшет
- **iPad (Safari):** откройте адрес → кнопка «Поделиться» → **«На экран „Домой“»**.
- **Android (Chrome):** откройте адрес → меню ⋮ → **«Установить приложение»**
  (или «Добавить на главный экран»).

После первого открытия приложение работает и без интернета.

> ⚠️ Ноты хранятся в памяти браузера на планшете. Периодически делайте
> **«Резервную копию»** — особенно перед удалением приложения или сменой устройства.

### Запуск на компьютере (для проверки)
```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `index.html`, `css/styles.css` | Интерфейс |
| `js/app.js` | Запуск, переключение экранов |
| `js/library.js` | Библиотека, импорт, резервные копии, печать |
| `js/editor.js` | Просмотр страниц, инструменты, стилус и жесты |
| `js/render.js` | Отрисовка нотного стана, PDF, изображений и пометок |
| `js/db.js` | Хранилище (IndexedDB) |
| `sw.js`, `manifest.webmanifest` | Работа без интернета и установка на экран |
| `vendor/pdfjs/` | [PDF.js](https://mozilla.github.io/pdf.js/) 4.10.38 (Apache 2.0) для показа PDF |

Пометки хранятся отдельно от исходного PDF/изображения в виде векторных штрихов,
поэтому оригинал нот никогда не портится, а пометки остаются чёткими при любом масштабе.
